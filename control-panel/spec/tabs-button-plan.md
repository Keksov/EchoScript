# tabs-button — план

## Запрос владельца

В UI, в левом верхнем углу таблицы сервисов (пустая ячейка заголовка слева от «Сервис»), —
иконка, открывающая консольное окно (Windows Terminal) со вкладками логов всех
**запущенных** демонов.

## Решение

Вся механика уже есть — `echoctl daemons tabs` (открывает echotail-вкладки работающих
демонов; tab-reuse не даёт дублей; остановленные пропускаются). Остаётся:

1. **Сервер панели**: `POST /api/daemons/tabs` → `echoctl daemons tabs --json` → форвард
   результата (`[{name, port, opened}]`).
2. **UI**: иконка-кнопка (terminal) в пустой 32px-ячейке заголовка таблицы демонов
   (`OverviewPage`), tooltip i18n en/ru, busy-состояние на время вызова; после — уведомление
   сколько вкладок открыто/переиспользовано. Пересборка ассетов (`quasar build` →
   `server/public`).

Замечание: wt открывает вкладки в текущем/последнем окне WT (`-w 0`), создавая окно при
отсутствии — то, что нужно «открыть консольное окно со всеми вкладками».

## Решения

- **TB-D1** кнопка — тонкая обёртка над `echoctl daemons tabs` (echoctl остаётся единственным
  механизмом вкладок); никакой логики в панели.
- **TB-D2** размещение — пустая ячейка заголовка слева от «Сервис» (левый верхний угол
  таблицы), иконка `terminal`.

## Фазы

- **P0** План + леджер.
- **P1** Endpoint + кнопка + i18n + ребилд — gate: клик по иконке в панели → окно WT со
  вкладками работающих демонов (повторный клик дублей не плодит); API отвечает списком.

## Конвенции

Один шаг → один коммит → один гейт. Ветка `feature/tabs-button` от master (tab-reuse и
daemons tabs уже там).
